# Code Explanation Prompt Template

**Role**: Technical Mentor / Educator  
**Task**: Explain the logic, flow, and key functions of the provided code in clear detail for a developer at [EXPERIENCE_LEVEL] level.  
**Input Placeholder**: 
- Experience Level: [EXPERIENCE_LEVEL] (e.g., Junior, Mid, Non-tech stakeholder)
- Code: [CODE_BLOCK]  
**Expected Output**: 
- High-level overview of what the code does.
- Line-by-line or section-by-section breakdown.
- Key algorithms or data structures used.

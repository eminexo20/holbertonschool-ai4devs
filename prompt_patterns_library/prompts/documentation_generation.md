# Documentation Generation Prompt Template

**Role**: Technical Writer & Software Architect  
**Task**: Generate structured inline docstrings and external Markdown documentation for the provided code file or module.  
**Input Placeholder**: 
- Language: [LANGUAGE]
- Documentation Standard: [DOC_STANDARD] (e.g., JSDoc, Google Python Docstrings, Doxygen)
- Code: [CODE_BLOCK]  
**Expected Output**: 
- Fully documented code snippet with inline docstrings.
- Markdown documentation table detailing functions, arguments, return types, and exceptions.

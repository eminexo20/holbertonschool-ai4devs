# Environment Setup Notes

## Overview
This document outlines the development environment, IDE configuration, AI coding assistant setup, and productivity tracking tools configured for the **Copilot Productivity Sprint**.

## 1. IDE & Core Tools
- **IDE:** Visual Studio Code (v1.96+)
- **Operating System:** Windows 11
- **Runtime & Languages:** Node.js (v20.x LTS), Python (3.12.x), JavaScript (ES6+)
- **Version Control:** Git (v2.45+) & GitHub (`eminexo20/holbertonschool-ai4devs`)

## 2. AI Coding Assistant Setup
- **Assistant:** GitHub Copilot & GitHub Copilot Chat (Built-in / Official GitHub Extension)
- **Plan:** Copilot Free
- **Setup Steps:**
  1. Opened Visual Studio Code and navigated to the **Extensions** panel (`Ctrl + Shift + X`).
  2. Verified **GitHub Copilot** and **GitHub Copilot Chat** extensions were installed and enabled.
  3. Clicked the Copilot icon in the bottom Status Bar, selected **Use AI Features**, and authenticated via GitHub account (`eminexo20`).
  4. Verified inline code suggestions (ghost text) and side-panel chat (`Ctrl + Alt + I`) in a test JavaScript file.

## 3. Time & Quality Tracking Tools
- **Time Tracking:** Stopwatch / Manual Lap Timer (per-task execution timing in seconds/minutes)
- **Testing & Verification:** Jest / Node built-in test runner (`node --test`) & `pytest` for Python tasks

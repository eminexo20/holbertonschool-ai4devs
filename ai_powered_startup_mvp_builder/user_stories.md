# User Stories - EcoRide MVP

## User Story 1
As a university student or commuter, I want to sign up and verify my institutional email address so that I can join a trusted ride-sharing community.

## User Story 2
As a driver, I want to post a daily commute ride with origin, destination, departure time, available seats, and suggested fuel split so that riders on my route can join me.

## User Story 3
As a rider, I want to search and filter available rides by origin, destination, and departure date so that I can find a commute that matches my schedule.

## User Story 4
As a rider, I want to request and reserve an available seat on a ride so that my spot is secured before departure.

## User Story 5
As a driver, I want to accept or decline incoming seat booking requests so that I maintain control over who travels in my vehicle.

## User Story 6
As a confirmed rider or driver, I want to send and receive messages inside a trip-specific chat thread so that we can coordinate the exact pickup spot and arrival time.

## User Story 7
As a commuter, I want to view my estimated money saved and CO2 emissions reduced on my dashboard so that I can track my financial and environmental impact.

## User Story 8
As a rider or driver, I want to leave a star rating and short review after a completed trip so that reliable community members build visible trust scores.

## User Story 9
As a driver, I want to cancel or edit an upcoming ride listing with automatic status updates to booked riders so that passengers are notified immediately of schedule changes.

## User Story 10
As a user on a mobile phone, I want to access all search, booking, and chat features through a responsive mobile web interface so that I can manage rides while on the go.
